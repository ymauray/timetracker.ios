# Obtenir de l'aide

- **Question d'utilisation** : ouvrez une [Discussion](https://github.com/ymauray/timetracker.ios/discussions).
- **Bug ou comportement inattendu** : ouvrez une [issue](https://github.com/ymauray/timetracker.ios/issues/new/choose) avec le modèle « Bug report ».
- **Demande de fonctionnalité** : ouvrez une [issue](https://github.com/ymauray/timetracker.ios/issues/new/choose) avec le modèle « Feature request ».
- **Question sur le calcul ou le format `releve.md`** : il est partagé avec la CLI, voir [ymauray/timetracker](https://github.com/ymauray/timetracker).
- **Vulnérabilité de sécurité** : voir [SECURITY.md](SECURITY.md), ne pas utiliser une issue publique.

Ce projet est maintenu sur mon temps libre ; il n'y a pas de garantie de délai de réponse.
